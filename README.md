# Fexxwer TheDev — Portfolio

Trang portfolio cua Fexxwer TheDev: Roblox gameplay scripter, GUI template, Blender model, shop source code, game mini chip ao va ghi chep trading.

**Xem web truc tuyen:** https://lupindsama.github.io/Fexxwer

## Co gi trong web

- **Home** — gioi thieu, ky nang, nhan commission tu 20 USD
- **Shop** — Discord bot source, dashboard UI kit, Roblox GUI template, portfolio template, script auto farm
- **VFX / GFX** — pack hieu ung va thumbnail thiet ke
- **Showcase / Tutorials** — san pham da xong va bai huong dan kem file mau
- **Projects** — game Sky Land tren Roblox (1 trong 4 dev chinh)
- **Models** — model Blender tu lam: sung AK, dao gam, sap cho
- **Games** — Blackjack va Texas Holdem choi bang chip ao (luu local)
- **Trading** — gia that tu Binance kem kien thuc nhanh
- **Status** — thong ke skill va muc do hoat dong

## Chay tren ca PC va mobile

- Giao dien sang/toi tu dong theo may, co nut doi tay
- PC: menu ngang day du. Mobile: thanh dieu huong duoi man hinh, bo cuc 1 cot
- Thiet ke lai theo nguyen tac tasteskill.dev (anti-slop frontend)
